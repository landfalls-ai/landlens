# History

Every change, in order, with the decisions along the way.

| Date | Change | Notes |
|---|---|---|
| 2026-11-14 | The study: project skeleton; OpenLens (`f1a960f`, its last open-source commit), Freelens (`2547f55`), the ACP spec (`13b7658`), the ACP TypeScript SDK (`b93e77b`) and claude-agent-acp (`7e857d5`) pinned in `scripts/fetch-upstream.sh`; Craft Anything 0.6.1 fetched and verified; the released Freelens 2.0.0 studied statically (fuses, asar inventory, app graph) and source graphs built; a live ACP handshake with Claude Code; four research reports, `research.md`; `plan.md` proposed | The user asked for an OpenLens-like IDE whose headline is an ACP client that runs their own Claude Code against the cluster they are looking at. Decisions proposed: Electron, a Go credential sidecar behind a token front door with a read-only policy for the agent, Landlens-owned approval for every write. Found: OpenLens's local proxy had no auth (Freelens added a token); both forks run the renderer with Node integration and no context isolation; Claude Code via ACP never uses client terminals and never asks in auto mode |
| 2026-11-14 | Plan approved; public repository `landfalls-ai/landlens` | Decisions (user): waves in the proposed order, agent before workbench; Landfall rooms only through Landflow's triage flow |
| 2026-11-14 | Wave 1, the shell: pnpm workspace; `landlens-kube-proxy` (Go, client-go) holds each cluster's credentials behind a per-process secret and mints the front door's loopback certificate; `@landlens/kube` (kubeconfig catalog, discovery, SelfSubjectAccessReview, paginated list + watch with bookmarks and 410 relist, a shared watch hub, the TLS front door with per-token policies and an audit trail, the tool kubeconfig with an env-only exec credential); `@landlens/contracts` (zod-validated IPC); the Electron app (sandboxed renderer, preload bridge, CSP, navigation and permission guards; catalog, sidebar from discovery, virtualized live tables, details with containers, conditions, events and YAML); fuses script; docs `architecture.md`, `security.md`, `development.md`, `limitations.md`, `roadmap.md` | Checked live on OrbStack: 24 pods across namespaces update live; an agent-style read-only token's `kubectl get pods` works while `kubectl delete pod` and `kubectl get secrets` are refused by Landlens before the cluster sees them; the IDE token reaches the API server; Secret values never reach the renderer. Changed from the plan: the front door is TLS + HTTP/1.1 (kubectl sends credentials only over TLS; the renderer uses IPC, so HTTP/2 isn't needed); kubeconfig parsing without `@kubernetes/client-node`. Craft Anything confirmed the hardened fuses on a cloned Electron.app. Tests: 34 kube, 10 desktop, 5 Go, 7 integration, 6 e2e |
